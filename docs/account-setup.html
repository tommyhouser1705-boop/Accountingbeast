Easier option: deploy through GitHub

If your Supabase project already exists, this action installs the database, approves your owner email, configures the website origin, and deploys the account server.

  1. Create a personal access token in Supabase account settings. Keep the token private.
  2. Open GitHub’s new repository secret. Name it SUPABASE_ACCESS_TOKEN, paste the token as its value, and save it. Do not paste it into chat.
  3. Open Set up Ledger Lane accounts. Click Run workflow, enter your owner email, and run it on main.
  4. When the run finishes with a green check, return to Ledger Lane and sign in with your existing account.

The action needs a Supabase management token. Connecting GitHub by itself does not grant it deployment access. Alternatively, use the manual steps below.

1. Create the free project

Open Supabase, choose New project, and name it Ledger Lane. Choose a region near your students. Keep the database password private. Wait until the project is ready.

In Authentication → URL Configuration, set Site URL to https://tommyhouser1705-boop.github.io/Accountingbeast/. Add that exact URL to Redirect URLs. In email provider settings, keep email confirmations enabled; set the minimum password length to 12. The built-in email service is limited, so use custom SMTP for a class pilot with multiple testers.

2. Add the classroom database

3. Add the account server

  1. Open Edge Functions. Create a function named classroom using the editor.
  2. Replace the starter code with the prepared code below and deploy it. Turn off the function’s platform Verify JWT setting. The function checks every user’s token with Supabase Auth itself.
  3. In Edge Function Secrets, add APP_ORIGIN with value https://tommyhouser1705-boop.github.io (no path or trailing slash). Supabase supplies the server credentials automatically. Never put a service-role key on the website.

4. Connect the website

Open the project’s Connect dialog or Settings → API Keys. Send the project URL and publishable key back in our conversation. These are public browser settings. Do not send a secret key, service-role key, database password, or personal access token.

I can then add those settings to the website and check the connection. Until they are added, Sign in explains that account hosting is not connected.

5. Try your first class

  1. On Ledger Lane, click Sign in → Create invited account using your owner email. Confirm your email, then sign in.
  2. In My classroom, approve a professor’s email or create your own class.
  3. Add students’ emails to the class. Share the site link yourself; authorization does not send an invitation email.
  4. Students create an account using their approved email and design their business.
  5. Review and publish a lesson to your selected class. Students receive it in their assignment list; their submitted work appears in your gradebook.
